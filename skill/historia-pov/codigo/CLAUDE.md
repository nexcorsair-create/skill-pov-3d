# Estúdio de histórias POV

Pasta criada pelo instalador do **historias-pov**. Para criar uma história, peça: **"monta uma história"** (a skill `historia-pov` conduz tudo, por etapas com aprovação).

- Fale com a pessoa no idioma dela, em linguagem simples, em termos de vídeo (ela pode não ser programadora).
- `estudio/` é o projeto de animação (Remotion + three.js); `historias/<nome>/` guarda tudo de cada história.
- Antes de continuar uma história, leia o `historias/<nome>/ESTADO.md` dela.
- **Nunca abra, mostre ou peça a chave** do `estudio/.env.local`. Os scripts leem sozinhos com `node --env-file=.env.local`.
- Diga o custo em créditos antes de gerar vozes. Nada é publicado sem a pessoa.
